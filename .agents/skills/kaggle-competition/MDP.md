# 竞赛外环 MDP 设计：提交不是终点，反馈是观测

> 设计日期：2026-10-11；**2026-10-14 修订**：γ→T 正名、P 分量积分解、Φ 势函数奖励、FSM 形式化、工具链外迁 references/（本文管形式化与设计理由，操作面以 [references/](references/) 为准）、案例引用闭环（skill 目录自包含）。来源实证：一次人工定性评审赛的三提交记录（提交号 57066228 / 57066435 / 57066480，2026-10-11）。π 在 agent（LLM）；环境面 = kaggle 平台（校验器/评审/预算），kaggle MCP 只是传感器与执行器。本文不训练策略，只把回路变成可审计、预算感知的控制结构。

## 0. 一句话

竞赛解题不是「看题→做题→提交」的开环流程，而是**外环 MDP**：提交只是动作之一，提交后的平台反馈（校验错误/分数/排行榜/讨论区）是一等观测通道，驱动 revise 重规划；提交预算（每日 5 次）使 submit 成为稀缺动作，preflight 把平台约束**本地化**，不把预算花在可本地判定的失败上。

## 1. 实证动机：三次提交的教训链

| 提交 | 包内 csv/parquet | 平台反馈 | 外环响应 |
| --- | --- | --- | --- |
| 57066228 | 11 个 | ERROR: multiple files with .csv/.parquet | 推断约束方向：数据文件要少 |
| 57066435 | 0 个 | ERROR: No .csv or .parquet found | 夹逼收敛：**恰好一个** |
| 57066480 | 恰好 1 个 | 无 ERROR（通过） | 终止提交子回路 |

三条结构性教训（本设计的动因）：① **平台校验器是环境的一部分**，其规则不在题目文档里，只能经反馈通道暴露；② **反馈有延迟且可能缺席**（人工评审可能永不下发）——终止不能建立在"收到评审反馈"上；③ **submit 是预算动作**——凡平台约束可本地复判的，preflight 拦截。

## 2. 两层结构：外环套内环

外环（SPEC→DATA→SOLVE→PACKAGE→SUBMIT→POLL，REVISE 回边）中，`solve` 是**方法开放插槽**：外环给内环的只有**冻结数据快照 + SPEC 产物**；内环回外环的只有**交付物 + 验证报告**。内环不必须是 MDP——是任意满足"可复现 + 可验证"两条硬要求的求解过程（mflowy 清洗/建模会话是已实证的 MDP 化实例之一；求解方式用户指定 > π 按题型自选，决策权序住 solve reference）。外环不感知内环步级状态，内环不感知提交存在——各自可独立复现。

## 3. 外环形式化（有限视野、部分可观测）

### 状态 S：两族分离

- **state = artifacts**（解题状态）：数据快照、SPEC 笔记、交付物、提交包、验证报告——π 本地拥有并推进的世界
- **info**（平台持有 + 导航信号，π 只读）：`gates`（规则接受门=人工、预算门=平台强制）、`submissions`（提交历史——**是决策输入**：预算计数/重试指纹/poll 目标都从它派生，非纯审计面）、`feedback`（上次提交反馈；无分赛 `feedback=∅` 是常态）+ 派生账本 `phase` / `cumulative_reward` / `should_stop`
- `phase = 回卷(最深已达成判据(artifacts), feedback 类别)`——**导航记录而非环境态**，正向是判据水位线，REVISE 按反馈类别卷回

### 动作 A：锁定动词表 + 开放插槽

锁定面 = 平台交互动词（query/download/build/lint/submit/poll/revise/escalate/STOP，工具链分见各 reference）；开放面 = `solve`（连"用什么工具集"都是决策内容）。菜单无集中 propose——**references/ 按阶段懒加载即静态介质的 propose(s)**：进入阶段才读该阶段后端，骨架常驻 = 契约层。

### 观测 O：poll 是感知动作

反馈四类（校验失败/评分异常/无反馈/讨论区信息）→ 各自决定 revise 回退点；通道矩阵见 poll-revise reference。**环境自转移**：评审在评、榜在变、讨论区在长、日预算在重置——世界在 agent 不动作时也演化，这是 poll 存在的理由，也是终止判据必须含"通道已扫"的原因。

### 转移 P：分量积 + 双段提交

$$P(s'|s,a) = P_{phase}(\text{π 判据}) \times P_{artifacts}(\text{本地确定}) \times P_{gates}(\text{平台/人工}) \times P_{submissions}(\text{平台异步}) \times P_{feedback}(\text{外生})$$

随机性全部住在后三分量；前两分量给定观测后确定。**submit 是双段转移**：即时段（预算 −1 + ref；技术失败无 ref = 预算未扣）与延迟段（校验结果经 poll 揭示）——"提交后立即 poll"的 P 依据。FSM（判据/反馈/守卫三列的完整转移表）的定性压缩住 SKILL.md 骨架；SUBMIT 出边三重守卫：预算>0 ∧ 规则门过 ∧ 指纹未失败过（重试守卫沉在 lint 脚本，非纪律）。

### 奖励 R：Φ 势函数（账面，非优化目标）

**Φ(s) = 100·1[存在过校验通过的提交] + best_score(s) − 100·n_failed(s)**，r = ΔΦ：

| 事件 | r |
| --- | --- |
| 提交→ERROR | −100（按次） |
| 首次过校验 | +100 |
| poll 揭示 score > best | +Δscore（best 取 max，棘轮——只有提升有正奖励） |
| 过校验但 score ≤ best | 0（烧掉的预算是结构性疼痛，不数值化） |
| 其余一切动作 | 0（诚实：真信号只在提交/评分时刻；过程整形信号是本地验证门） |

终局 R = Φ(s_DONE)。best_score 方向按 metric 归一（MAE 类取负方向）；无分赛 best_score=∅ 记 0，终局 R=100，与终止条件解耦一致。Φ 由 submissions.json 账本承载、decision 可重放——π 读的是定性信号（lint 绿/分数升/ERROR），数值不进骨架（reward 是观测不是目标）。

### 视野 T 与 γ

T 三层叠加：competition deadline（**吸收壁，episode 的真视野**——DONE 在此之前非吸收，可重开）；日预算 5 次（可再生资源约束，平台强制）；"无 revise 空间→中止次日续"（π 判定）。多日续局是同一 episode。**γ 退化**：回合制 + 有限视野 ⇒ γ=1 未建模——代价不对称（submit ≫ 其余）+ T 才是真结构；deadline 邻近从探索转向保守提交是策略层考量，不是环境参数。

## 4. Preflight：约束本地化（dry_run 的外环对应）

lint = 零成本假想转移——把黑箱平台校验器内化为本地判定，等价于把「ERROR 才发现约束」的失败变成「lint 拦截」的零成本发现。守卫来源是**归纳**：每条 error_description 回流一条规则（对照 clean MDP 的守卫来自问卷先验）——规则表住 package reference，实现住 `scripts/submission_lint.py`（活脚本，飞轮单点生长；重试守卫=指纹比对同住脚本）。

## 5. 落地与复用

布局三层 = 契约/菜单/守卫的文件投影：SKILL.md 骨架（常驻状态机+不变量，零工具名）、references/ 六阶段（propose(s)，进入才读）、scripts/ 活 lint。通用化留白（未实现，接口先立）：外环动作幂等命令化后，任何竞赛以同一控制回路驱动，可直接套用仓库已收敛的会话契约（P 包平台调用、T=quota、守卫=lint、FinishVerdict=校验通过∧通道已扫）。
